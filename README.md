# AI-Based Tic-Tac-Toe Game

## About the Project

This project is an AI-Based Tic-Tac-Toe game developed using Python.
It allows a human player to play against an AI opponent that makes
decisions using the Minimax algorithm.

The game provides three difficulty levels: Easy, Medium, and Hard.
It also maintains game history and a scoreboard to track the results.

## Features

- Play Tic-Tac-Toe against an AI opponent.
- Three difficulty levels: Easy, Medium, and Hard.
- Minimax algorithm for intelligent AI decision-making.
- Randomized move selection when multiple moves are equally good.
- Scoreboard showing player wins, AI wins, and draws.
- Win-rate percentages for the player, AI, and draws.
- Permanent scoreboard storage using JSON.
- Game history stored in a JSON file.
- Input validation for invalid or occupied positions.
- Simple command-line interface.

## Technologies Used

- Python
- Minimax Algorithm
- JSON
